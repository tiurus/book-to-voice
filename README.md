# Книжный голос

Приватный веб-сервис русской озвучки на Silero TTS `v5_5_ru`. Он озвучивает отдельный текст или ставит длинные TXT-файлы в очередь, последовательно синтезирует безопасные фрагменты, объединяет их в WAV и локально создаёт MP3 через FFmpeg. После первоначальной загрузки модели интернет для работы не нужен.

## Быстрый запуск на macOS Apple Silicon

Нужны Homebrew, Python 3.12 и FFmpeg:

```bash
brew install python@3.12 ffmpeg
make dev
```

`make dev` сам создаёт `.venv`, устанавливает зафиксированные зависимости и запускает сервис только на `127.0.0.1:8000`. Откройте [http://127.0.0.1:8000](http://127.0.0.1:8000) для отдельного текста или [страницу очереди файлов](http://127.0.0.1:8000/file-queue.html). При первом запуске модель размером около 100 МБ будет загружена в `data/models`; последующие запуски используют локальную копию.

Проверка без загрузки настоящей модели:

```bash
make test
make lint
```

Для ручной проверки всех голосов по очереди используйте тексты из раздела «Проверка качества» ниже. На MacBook Air длительный синтез может нагревать устройство — это ожидаемо для CPU-задачи.

## Запуск через Docker Compose

```bash
docker compose up --build -d
docker compose logs -f tts
```

Контейнер собирается для целевого `linux/amd64` и устанавливает CPU-only сборку PyTorch без CUDA. Он использует один worker, не более одной одновременной генерации, четыре CPU и лимит памяти 5 ГБ. Порт опубликован только на `127.0.0.1:8000`, поэтому извне сервер напрямую недоступен. Доступ организуйте через SSH-туннель, приватную LAN/VPN или уже настроенный reverse proxy:

```bash
ssh -L 8000:127.0.0.1:8000 home
```

После этого откройте `http://127.0.0.1:8000` на Mac. Политика `restart: unless-stopped` автоматически возвращает контейнер после перезагрузки Docker/сервера. Модель и записи находятся в именованных Docker volumes и не исчезают при пересоздании контейнера.

Для развёртывания текущего checkout на SSH-алиас `home`:

```bash
./scripts/deploy-home.sh
```

Скрипт копирует только исходники и конфигурацию в `~/services/book-to-voice`, затем выполняет `sudo docker compose up --build -d` и проверяет health endpoint. Он не удаляет посторонние файлы на сервере.

## API

| Метод | Маршрут | Назначение |
|---|---|---|
| `GET` | `/api/health` | готовность модели и размер очереди |
| `GET` | `/api/voices` | голоса, частоты и возможности модели |
| `POST` | `/api/speech` | поставить синтез в очередь |
| `GET` | `/api/jobs/{job_id}` | получить состояние и ссылки результата |
| `POST` | `/api/file-jobs` | загрузить TXT и поставить его в общую очередь |
| `GET` | `/api/file-jobs` | показать очередь загруженных файлов |
| `GET` | `/api/file-jobs/{job_id}` | прогресс по фрагментам и итоговый результат |
| `GET` | `/api/audio/{file_id}?format=wav` | прослушать WAV или MP3 |
| `DELETE` | `/api/audio/{file_id}` | удалить оба формата результата |

Пример запроса:

```bash
curl -sS http://127.0.0.1:8000/api/speech \
  -H 'Content-Type: application/json' \
  -d '{"text":"Привет! Сегодня тридцать первое августа.","voice":"xenia","sample_rate":48000,"speed":"normal","auto_stress":true}'
```

`POST /api/speech` отвечает `202` и возвращает `job_id`. Состояния: `queued`, `processing`, `completed`, `failed`. Очередь ограничена восемью ожидающими заданиями; при переполнении возвращается `429`. Pydantic не допускает неизвестный голос, частоту или скорость, пустой текст и управляющие символы.

Страница очереди принимает `.txt` в UTF-8 или Windows-1251 размером до 2 МБ и длиной до 500 000 символов. Обычные запросы и файлы используют одну очередь, поэтому одновременно работает ровно один синтез. Для длинного файла каждый фрагмент сразу записывается на диск; вся будущая аудиокнига не накапливается в RAM. Интерфейс показывает позицию, число готовых фрагментов, этап объединения и преобразования, а после завершения предлагает единые WAV и MP3.

Расширенный режим принимает SSML с корнем `<speak>` и безопасным подмножеством тегов: `p`, `s`, `break`, `prosody`. Произвольные теги и атрибуты отклоняются до передачи модели. В SSML ударения при необходимости отмечаются вручную знаком `+` перед ударной гласной.

## Хранение и приватность

- Пользовательский текст не записывается в логи и не сохраняется на диск.
- WAV, MP3 и короткий JSON с техническими метаданными хранятся в `data/audio` или Docker volume.
- Имена файлов — случайные UUID и не содержат пользовательского текста.
- Файлы автоматически удаляются через 24 часа; срок меняется через `TTS_RETENTION_HOURS`.
- Временные файлы очищаются после ошибки и при периодической уборке.
- Ни backend, ни интерфейс не обращаются к облачным API. Единственный внешний запрос — однократное получение файла модели с `models.silero.ai`, если его ещё нет локально.

Переменные конфигурации перечислены в [`.env.example`](.env.example). В Docker их задают в `compose.yaml`; при обычном запуске — через окружение перед `make run`.

## Проверка качества

Рекомендуемый ручной набор:

```text
Обычный текст. За окном шёл тихий дождь, и старый дом постепенно засыпал.
Правда ли, что поезд отправится завтра? Какой чудесный вечер!
На двери висел старый замок, а рыцарь поднял тяжёлый замок над головой.
31 августа 2026 года в 18:45 ООО «Вектор» открыло 3 филиала.
Ёж нашёл жёлуди под ёлкой и бережно сложил их в корзину.
«Ты вернёшься?» — спросила она. «Обязательно!» — ответил он.
```

Добавьте текст длиннее 900 символов, чтобы проверить стыки фрагментов. Для каждого из `aidar`, `baya`, `kseniya`, `xenia`, `eugene` оцените разборчивость, ударения, паузы, окончания и отсутствие щелчков. Healthcheck подтверждает загрузку, но не заменяет прослушивание реального результата.

## Типовые проблемы

- **`model_load_error`** — проверьте свободное место, первый сетевой доступ и права на `data/models` или volume `silero-models`.
- **Ошибка MP3/FFmpeg** — убедитесь, что `ffmpeg -version` работает; в Docker он уже установлен.
- **Контейнер долго `starting`** — первая загрузка модели входит в `start_period: 180s`; посмотрите `docker compose logs tts`.
- **Процесс завершён из-за памяти** — проверьте `docker stats`, наличие swap и оставьте один worker.
- **Нет доступа с другого компьютера** — это безопасное поведение по умолчанию. Используйте SSH-туннель, VPN или reverse proxy; не меняйте binding на `0.0.0.0` без сетевого ограничения.

## Лицензия модели

Код этого проекта предназначен для личного локального использования. Русская модель Silero V5 распространяется на условиях **CC BY-NC** и не должна использоваться коммерчески без отдельного разрешения или замены на модель с подходящей лицензией. Актуальные голоса `v5_5_ru` (`aidar`, `baya`, `kseniya`, `xenia`, `eugene`), частоты и условия проверяйте в [официальном репозитории Silero Models](https://github.com/snakers4/silero-models) перед распространением или развёртыванием в иной среде.
